# ペラっと（Peratto）

29卒向けインターン参加支援。中央のアイランドウィンドウで絵本を読み、初日だけアイスブレイクに参加する Web アプリ。

**スマートフォン・PC 両対応**（720px 以下でレイアウトが1カラムに切り替わります）。

---

## サイトの使い方（参加者）

### 1. ホーム（`/`）

- 本棚から **6冊の絵本** をタップ／クリックして読めます。
- ページをめくると **RewardTrack（読書リワード）** がたまります。Lv が上がると、アイスブレイクの「書く時間」が最大 +10 秒されます（端末の `localStorage` に保存）。
- 左右の **‹ › ボタン** で、読んだ本の履歴を行き来できます。

| 本 ID | タイトル |
|-------|----------|
| `it` | IT業界とは？ |
| `it-jobs` | IT業界での職種 |
| `nano` | ナノコネとは？ |
| `gf` | GFとは？ |
| `work` | 労働環境 |
| `intern` | インターンについて |

例: `/book/it` で「IT業界とは？」を開けます。

### 2. アイスブレイク（`/icebreak`）

管理者が **開始** すると、ホーム下部に「アイスブレイクに参加」ボタンが出ます。

1. **ニックネーム**（12文字まで）を入れて「入る」
2. **ロビー** — 2人揃うと自動でお題へ（1人だけのときは管理者が「1人でもお題へ」で進行可能）
3. **お題** — 4秒間表示
4. **描く** — 45秒 + 読書リワードボーナス（最大+10秒）。終了間近で自動送信
5. **評価** — 届いた絵を最大3枚、おもしろさ・きれいさ・わかりやすさを各5段階で評価
6. **結果** — 自分の順位とスコア（この場限り）

同じ端末で再度入る場合、ニックネームと secret が `sessionStorage` に残っていれば再接続できます。

### 3. 会場スクリーン（`/screen`）

投影・司会用。参加者一覧・お題・タイマー・順位・トップ3の絵が表示されます。参加者が `/icebreak` を開いている間、こちらを会場モニターに映します。

## 管理画面（`/admin`）

URL を直接開いて使います（ホームからのリンクはありません）。

### デモ版ログイン（公開可）

| 項目 | 値 |
|------|-----|
| 管理者名 | `admin` |
| パスワード | `change-me-before-deploy` |

`.env` の `NUXT_ADMIN_USER` / `NUXT_ADMIN_PASS` で変更できます。本番運用時は必ず差し替えてください。

### 管理画面でできること

| セクション | 操作 |
|------------|------|
| **アイスブレイク** | 「開始」で場をオープン。「場をやり直す」でリセット。ロビー中は「1人でもお題へ」。「投影」で `/screen` を開く |
| **お題** | 周数（1〜8）とお題文の編集・保存（次の開始から反映） |
| **本の公開** | 6冊それぞれ「表示／隠す」。非公開の本は一覧に出ず、URL 直打ちもゲートされます |
| **インターン情報** | 日程・会場・Zoom・リンクなどポータル文言の編集 |

### 当日の進行例

1. 事前に `/admin` で本の公開・ポータル・お題を確認
2. 参加者に `/` で絵本を読んでもらう（任意）
3. 開始時刻に **開始** → 参加者に `/icebreak` へ案内
4. 会場には `/screen` を投影
5. 全周終了後、結果画面で締め

## セットアップ（開発者向け）

```bash
npm install
cp .env.example .env
# デモのままなら NUXT_ADMIN_PASS=change-me-before-deploy で可
npm run dev
```

ブラウザで http://localhost:3000 を開きます。

| URL | 用途 |
|-----|------|
| `/` | ホーム・本棚 |
| `/book/[id]` | 絵本 |
| `/icebreak` | アイスブレイク参加 |
| `/screen` | 会場投影 |
| `/admin` | 管理 |

```bash
npm run build
node .output/server/index.mjs   # 本番起動
```

## 試作運用の制約（重要）

このリポジトリは **当日試作** 向けです。数百人規模は想定していません。

| 項目 | 制約 |
|------|------|
| 状態 | **`.data/` に JSON + 画像ファイル**。単一 Node プロセス前提 |
| プロセス | **1 プロセス 1 ルーム**。水平スケール不可 |
| 参加者 | 最大 **20 人** |
| 管理者 | 環境変数 `NUXT_ADMIN_*`（上記デモ値可） |
| プレイヤー | join 時に `playerSecret` 発行。submit/vote に必須 |
| 本の非公開 | 一覧非表示 + API で readable チェック（本文はバンドル内） |
| 読書リワード | `localStorage` のみ。デバイス間で共有されない |
