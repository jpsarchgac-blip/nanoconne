## 1. 一言コンセプト

**舞台の中央に窓があり、その中で絵本が動き、初日だけ短く遊んでナノコネを覚える。**

探す人には、マイナビの隣にある体感の入口。  
参加する人には、公開された本に加え、初日だけのアイスブレイク。  
進行は開始ボタン一つ。会場のスクリーンにはニックネームと順位がそのまま出る。

---

## 2. なぜ立体絵本を捨てるか

立体絵本は「めくると情報が立ち上がる」体験として魅力はあった。一方で、編集・作成側を期間内に本番品質まで持っていく難易度が高く、企画の本丸（29卒の支援とナノコネの体感）よりエンジン開発が主になりうる。

捨てるのは立体エンジンだけである。

- **残す**：絵本という語り口、短い一話、アニメーション、アイランドの中で完結する操作
- **捨てる**：3D紙、作成ツール、pop-up の再現

平面の見開きと、CSS / 2D の動きで「ただの記事サイトではない」を出す。特徴は立体ではなく、**アイランドウィンドウという器**で出す。

---

## 3. 画面の約束（一線を画す点）

普通の Web（上にグローバルバー、左にメニュー、下がコンテンツ）にしない。

```
┌─────────────────────────────────────┐
│              舞台（余白）            │
│         ┌─────────────────┐         │
│         │                 │         │
│         │  アイランド窓    │         │
│         │  ここで全部完結  │         │
│         │                 │         │
│         └─────────────────┘         │
│                                     │
└─────────────────────────────────────┘
```

- 舞台：ナノコネの色（ベース `#01ACE0` と白）。ナビを置かない。
- アイランド：角丸の窓。本棚・本・アイスブレイク・管理の操作はすべてこの中。
- 会場スクリーン：`/screen`。同じシステム。窓の中がランキング・お題・タイマー・トップ3になる。
- ページ遷移で「普通のサイト」に戻らない。入口が違っても、窓の中身が差し替わるだけ。

## 6. 何をやるか / 何をやらないか

### やること（試作で実装済み）

1. アイランドウィンドウを唯一の操作面にする。
2. 絵本6冊（平面＋アニメーション）。管理者の表示／非表示。左ページの **太字・マーカー** 強調。
3. 参加初日のアイスブレイク。ニックネーム。開始ボタン。手書き→評価→スクリーンにリアルタイム結果。
4. 読書リワード（Lv.0〜5）→ アイスブレイクの書く時間ボーナス。
5. インターンポータル（日程・会場・リンク）の管理者更新。
6. ノートへはリンクだけ。

| やらない | 理由 |

| 上バー型の普通のサイト | 一線を画す、の約束 |
| 動画プレイヤー | ノートの仕事 |
| ランキングの永続・選考利用 | GF の場を評価にしない |
| 本番規模の同時接続を最初から | 試作は 20人・単一ルーム |

## 7. 体験の骨格

```
通年（探す人含む）          参加初日                     選考
表示中の本を窓で読む   →  開始 → ニックネーム入室     ノート（動画）
  RewardTrackで進捗         お題→手書き→3枚評価×2周
                         スクリーンに順位・トップ3
                         終了 → また本の窓へ（点は残さない）
```

### アイスブレイクの進行（実装）

1. 管理者が `/admin` で **開始**（または **場をやり直す**）。
2. ホームに **アイスブレイクに参加** が出る。参加者はニックネームで `/icebreak` に入室。
3. **lobby**（12秒）：2人以上で自動的に次へ。
4. **prompt**（4秒）：お題表示。円形タイマー付き。
5. **draw**（基本45秒＋読書ボーナス最大+10秒）：`DrawPad` で手書き。時間切れで自動送信→回収猶予1.5秒。
6. **vote**（48秒）：自分以外の絵3枚を、**おもしろさ・きれいさ・わかりやすさ** の5段階で評価。未入力軸は **3点** で補完。
7. 2周（管理者で1〜8周に変更可）終了後 **results**：自分のレーダーチャート。`/screen` にトップ3の絵。
8. お題はデフォルト14件。管理者が `/admin` で編集（次の開始から反映）。

司会が口頭で手順を増やさない。開始一つが約束。

## 12. リスク（試作後の所感）

1. **インメモリ**：再起動でルーム・お題設定・ポータル編集がリセットされる。本番前に永続化が必要。
2. **Zoom**：画面共有と `/screen` URL の二通り。試作は `/screen` を正とした。
3. **絵データ**：手書きは data URL（最大400KB）。人数×周数が増えると転送量に注意。
4. **管理者認証**：試作用固定パスワード。本番前に環境変数化が必要。
