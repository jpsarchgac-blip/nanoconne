## 1. システム概要

**ペラっと**は Nuxt 4 + Nitro の SSR/SPA ハイブリッド。中央のアイランドウィンドウ内で絵本6冊と、初日限定のアイスブレイクを提供する。

| レイヤ | 技術 |
|--------|------|
| フロント | Vue 3, Composables, コンポーネント |
| API | Nitro (`server/api/*`) |
| 状態 | 単一ルーム + `.data/` JSON/ファイル永続化 |
| 認証 | 管理者 Cookie + CSRF / プレイヤー secret |

## 6. 永続化（`.data/`）

再起動後も残る設定と、進行中ルームの復元。

| ファイル | 内容 | 更新タイミング |
|----------|------|----------------|
| `books.json` | 6冊の visible | 管理画面で切替 |
| `portal.json` | 日程・会場・リンク | 管理画面で保存 |
| `ice-topics.json` | 周数・お題リスト | 管理画面で保存 |
| `room.json` | ルーム状態（players, phase, votes…） | 参加・投票・フェーズ遷移 |
| `drawings/{uuid}.jpg` | 手書き画像 | submit 時 |

**注意**

- 単一 Node プロセス前提。複数インスタンスでは `.data/` が分裂する。
- ルーム復元後、`tickRoom()` が期限切れフェーズを自動進行する。
- 絵本本文は引き続きクライアントバンドル内。非公開は API ゲート + 一覧非表示。

## 7. アイスブレイク — 状態機械

```
idle ──(admin start)──► lobby ──(2人+12s | admin skip)──► prompt(4s)
                              │
                              ▼
                           draw(45s+α+回収1.5s)
                              │
                              ▼
                           vote(48s) ──► (次ラウンド) prompt …
                              │
                              ▼ (全周終了)
                           results (spotlight top3)
```

| 定数 | 値 |
|------|-----|
| 参加者上限 | 20人 |
| 評価軸 | おもしろさ / きれいさ / わかりやすさ（1〜5） |
| 未投票 | 3点/軸 |
| 割当 | 自分以外最大3枚 |
| デフォルト周数 | 2（管理で1〜8） |
| デフォルトお題 | 14件 |

**読書リワード**: `localStorage` の Lv.0〜5 → 書く時間 +0〜+10秒（クライアント演出。サーバーは最大待ち）。

## 8. API 契約

### GET `/api/room?playerId=&rev=`

- `rev` が現 revision と一致 → `{ unchanged, revision, serverNow }`（軽量）
- それ以外 → `IceRoomView`（ballots.image は `/api/drawings/{id}` URL）

### POST `/api/room`

| action | 認証 | body |
|--------|------|------|
| start | admin | — |
| skipLobby | admin | — |
| join | — | nick, playerId?, playerSecret? |
| submit | player secret | playerId, playerSecret, image |
| vote | player secret | playerId, playerSecret, drawingId, funny/beauty/clear |

### GET `/api/books/[id]`

`{ id, title, visible, readable }` — readable=false ならリーダー非表示
