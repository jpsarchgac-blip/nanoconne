インターン絵本の用語を、企画を通すために定義する。  
各語は **定義 / なぜ重要か / 境界 / 本企画での現れ方 / 状態** で書く。

凡例：確定＝資料または試作実装で根拠あり。仮説＝企画判断。未決＝要確認。

**2026-08-31 更新**：v0.3 企画段階から **試作完成** への変化を、各語の「現れ方」「状態」に反映した。

## 29卒

**定義**  
2029年3月卒業（2029年4月入社）を目指す学生。本企画の対象世代。20代前半が中心。大学・大学院・短大・専門・高専を含む（ナノコネのインターン対象に合わせる）。

**なぜ重要か**  
対象を「就活生全般」に広げると、マイナビと公式採用の仕事になる。29卒に閉じると、今年のインターン型に合わせた情報更新ができる。

**境界**  
28卒以前は採用ページ上、別導線（説明会・Web就活ノート）がある。本アプリの主対象にしない。

**現れ方**  
コピー、日程、コース説明は29卒の今年型。ポータル（`/api/portal`）とインターン絵本が連動。過去年の賞品額や日程を本文の確定値にしない。

**状態** 確定（依頼）。インターンの年次表記は公開情報とずれるため、運用時に管理者が差し替える。

## インターン / コンペ形式インターンシップ

**定義**  
ナノコネの強みであるゲーミフィケーションを組み込んだ Web サービスの企画・開発を、期間内に行い、第三者評価を受ける実務疑似体験。IT企画営業と ITエンジニアの2コース。文理OK、未経験OK。必須日と任意の作業日がある。入賞者に賞品がある。

**なぜ重要か**  
本アプリが支援する「場」そのもの。ポータルの中身も簡易イベントの進行も、この型に合わせる。

**境界**  
オープンカンパニーや会社説明会とは別。本アプリは説明会代替にしない。選考そのものでもない。

**現れ方**  
絵本「インターンについて」（7スプレッド）。日程・必須／任意・コース選択・提出と評価の流れ。賞品は事実として短く。煽り文句にしない。

**状態** 型は確定（依頼メモ＋採用ページ）。29卒の実日程・賞品額は管理者更新（試作ではポータルに初期値あり）。

## インターン参加支援

**定義**  
インターンに申し込む／参加する人が、判断と行動に必要な情報と体験を、必要なときに得られること。選考を代行することではない。

**なぜ重要か**  
依頼の製品名。広すぎると採用サイト全体になり、狭すぎると当日資料置き場になる。

**境界**  
参加支援 ≠ 内定支援。内定・エントリーは Web就活ノート。  
参加支援は探す人と参加する人の両方。公式採用ページの全文代替ではない。

**現れ方**  
公開層：絵本6冊。参加層：絵本＋ポータル＋アイスブレイク。提出はしない。アイスブレイクの点は当日限り。

**状態** 確定（相談 2026-08-30。両方）。試作で実装済み。

## 情報ポータル

**現れ方**

**状態** 確定。試作で管理者編集UI実装済み。永続化は未（インメモリ）。

## 簡易イベント / アイスブレイク

**定義**  
インターン当日の短い公式枠。**オンライン 5〜10分**。ナノコネを知りつつ、会場と Zoom が同じ場で楽しめる。**ランキングが表示される**。

**企画時**  
ゲームの種は未決（クイズか、絵本連動か）。

**試作完成**  
**お題→手書き→他人の絵を3枚評価** のループ。クイズではない。絵本の内容を暗記させる形式でもない。

**なぜ重要か**  
参加層の初日を温め、ゴール2を「説明」ではなく場の記憶にする。探す人向けの通年体験とは分ける。

**境界**  
アイスブレイク ≠ コンペ本体（賞品・成果物）。  
アイスブレイク ≠ Web就活ノートの動画。  
ランキング ≠ 選考資料。残して評価に使わない。  
サイト全体 ≠ ゲーム。ランキングはこの5〜10分の可視化に閉じる。

**現れ方**  
`/icebreak`（参加者）・`/screen`（投影）。フェーズ：lobby → prompt → draw → vote → results。  
評価軸：おもしろさ・きれいさ・わかりやすさ（各1〜5）。未投票は **3点**。  
デフォルト2周・14お題。`PhaseRingTimer`・`DrawPad`・`ScoreChart`。参加者上限20人。

**状態** 枠・進行・UIは **確定（試作完成）**。お題文は管理者が差し替え可能。

## 読書リワード

**定義**  
絵本をめくった進捗に応じて付く **Lv.0〜5**。GF の「リワード」要素の試作実装。選考スコアではない。

**なぜ重要か**  
通年の読書と初日の場を、GF で一本につなぐ。経験値バーではなく **書く時間のボーナス** に限定することで、選考化を避ける。

**境界**  
リワード ≠ 選考加点。  
リワード ≠ 全GF要素の実装。12要素のうち、サイト全体で触れるのは一部。

**現れ方**  
`RewardTrack`（ホーム）。`localStorage`（`peratto-progress`）でスプレッド閲覧を記録。  
Lv.1〜5でアイスブレイクの **書く時間 +2秒/Lv**（最大+10秒）。評価点には影響しない。

**状態** 確定（試作）。数値化はLv段階のみ（細かいXPは置かない）。

## GF / ゲーミフィケーション

**定義（確定・公式）**  
ゲームで夢中になる要素を論理的に分解し、ゲーム以外の課題解決やサービス向上に活かす技術。2010年代初頭から研究し、ナノコネは **12の要素** に集約。要件設計プロセスと Skywalker に組み込んでいる。公式に **GF** と略す。  
出典：[ゲーミフィケーション | 株式会社ナノコネクト](https://www.nanoconnect.co.jp/gamification/)

**中核（確定・公式）**  
**平均ユーザーレベル** — 今の利用者の熟練度・知識を想像し、設計の中心に置く。  
設計領域の4方向：世界観・難易度・仕掛け・ボリュームゾーン。  
上下：エンターテインメント（楽しませる）／コンセントレーション（集中）。  
左右：メカニクス／UI・UX。

**要件設計プロセス（確定・公式）**  
超上流（コンセプト・業務理解）→ 上流（仕様・画面・報酬）→ 運用（計測・改善）。

**12要素（確定・登壇解説）**  
出典：[デブサミ2019関西 レポート（CodeZine）](https://codezine.jp/article/detail/11779) ／ ナノコネ ゲーミフィケーション・エバンジェリスト 仲功児氏。  
コンセントレーション5（必須）＋ エンターテイン5 ＋ ユーザ像2。

| 領域 | 要素 | 一言 |
|------|------|------|
| 集中 | ペイン排除 | 中身と関係ないストレスをなくす |
| 集中 | レベルデザイン | 難易度の起伏 |
| 集中 | ゴール設定 | 向かう先を示す |
| 集中 | 可視化 | 進みを見える化する |
| 集中 | インターフェース | 触り心地 |
| 楽しむ | デザイアー | もっと知りたい欲求 |
| 楽しむ | ファーストキャッチ | 最初のつかみ |
| 楽しむ | コミュニケーション | 人とつながる |
| 楽しむ | リワード | 手間に釣り合う返し |
| 楽しむ | ディレクション | 次の行動を導く（登壇名はディレクション＆エフェクト） |
| ユーザ | 平均ユーザーレベル | いま来た人の知識に合わせる |
| ユーザ | チューンナップ | 出したあとも使い方を見て直す |

**Skywalker（確定・公式）**  
AI×GF の開発基盤。プラグイン方式で要素を組み合わせ、要件から運用まで支援。  
出典：[Skywalker 機能紹介](https://www.skywalker-cloud.com/features/)

**なぜ重要か**  
ナノコネの強みそのもの。本アプリが「ナノコネらしい」と言える唯一の中身。立体絵本・紙細工の略ではない。

**境界（確定・企画方針）**  
GF ≠ ゲームアプリ化。本編を育成ゲームにしない。  
GF ≠ ランキング目的化。アイスブレイクの順位は可視化の例であり、目的はナノコネを知ること。  
GF ≠ 装飾アニメ。めくるは UI。  
GF ≠ 選考経験値。採用スコア化は置かない。

**ペラっとでの対応（試作完成）**

| GF の考え方 | 企画時 | 試作での現れ方 |
|-------------|--------|----------------|
| ファーストキャッチ | 中央アイランド・本棚 | **同左**（`BookMarquee`） |
| 操作（UI） | 見開きをめくる | **同左**（`BookReader`） |
| 可視化 | アイスブレイクのランキング | **同左** ＋ 読書進捗ドット・`RewardTrack` |
| リワード | （未記載） | **読書Lv → 書く時間ボーナス** |
| コミュニケーション | （未記載） | **手書き共有・3枚評価** |
| 平均ユーザーレベル | 短いルート | **同左** ＋ 専門語は冊内定義・`**`/`==` 強調 |
| 置かないもの | 経験値バー・選考スコア | **同左** |

**現れ方**  
絵本「GFとは？」（5スプレッド）＋ `GfTwelveScene` デモ。通年は読書、初日はアイスブレイク。

**状態** 定義・中核は登壇資料で確定。試作で6要素程度を画面に実装。全部は実装しない方針を維持。

## Web就活ノート

**定義**
