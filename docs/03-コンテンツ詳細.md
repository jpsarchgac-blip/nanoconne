## 1. IT業界とは？（`it` · 5スプレッド）

### 目的

学生が、IT業界を職種名の羅列ではなく **棲み分けの地図** として持ち帰り、その上にナノコネがどこにいるかを置ける。

対応する動機：IT業界を勉強したい（アンケート 141）。

### 前提知識

不要。初めてのインターン、文系でも通せる。

### 語り口

教科書の章立てにしない。地図・ベン図・三つの場が **CSS アニメーション** で分かれ、最後にナノコネの整理が並ぶ。

### シーン構成（試作）

| 順 | 起承転結 | シーン | 文章の仕事 |
|----|----------|--------|------------|
| 起 | 起 | 業界は一つに見えない（map-split） | 同じ「IT」でも仕事が違う |
| 承 | 承 | 自社・受託・常駐（three-places） | どこで・誰のものを・どう作るか |
| 承 | 承 | 下請け構造（it-subcontract） | 委託の連鎖 |
| 転 | 転 | 技術領域（it-tech-domains） | Web・アプリ・AI 等の広がり |
| 結 | 結 | ナノコネの座標（it-nano-summary） | 社内開発・企画から運用まで |

### ポータル

用語カード（terms-cards）で一言定義。詳細リンクは公式へ。

### アイスブレイク

必須にしない。お題例：「23階の窓から見えるもの」「常駐じゃない開発を一枚」。

### Web就活ノートと被らない理由

ノートは「IT業界の全体像を学んだ」という **学習完了**。こちらは **ナノコネの座標までつなぐ一話**。

## 4. GFとは？（`gf` · 5スプレッド）

### 目的

GF がゲームではないこと、ナノコネが12要素で設計していること、このサイトもその考え方でできていることを、操作の記憶として残す。

対応する動機：GF に興味（112）。ゴール2の中核。

### 前提知識

不要。「ゲームが好き」は前提にしない。

### 語り口

定義のあと、要素が動き、最後に「この絵本がやっていたこと」とサイトの対応が並ぶ。

### シーン構成（試作）

| 順 | 起承転結 | シーン | 文章の仕事 |
|----|----------|--------|------------|
| 起 | 起 | ゲームではない（service-shift） | 公式定義の言い換え |
| 承 | 承 | ユーザを理解する（user-core） | 平均ユーザーレベル |
| 転 | 転 | 12要素（gf-twelve / GfTwelveScene） | タップでモーション。暗記させない |

| 結 | 結 | このサイトが GF（site-mirror） | 本棚・めくり・初日の場 |

### アイスブレイク

## アイスブレイク（コンテンツとして）

企画案では「ゲームの種未決」。試作では次の形で確定した。

| 項目 | 内容 |
|------|------|
| 形式 | お題 → 手書き（DrawPad）→ 他人の絵3枚を評価 |
| 評価軸 | おもしろさ・きれいさ・わかりやすさ（各1〜5） |
| 未投票 | 各軸 **3点** で自動補完 |
| 周数 | デフォルト **2周**（管理者で1〜8） |
| お題 | デフォルト **14件**（管理者編集可） |
| 時間 | lobby 12s / prompt 4s / 書く 45s（+読書ボーナス最大10s）/ vote 48s |
| 可視化 | `/screen`：ランキング・`PhaseRingTimer`・結果トップ3 |
| 読書連動 | Lv.0〜5 → 書く時間 +0〜+10秒（評価点には無関係） |
| 残さない | サーバー再起動で消える。選考資料にしない |

## 冊をまたぐ流れ

推奨順（強制しない）：

1. **インターンについて**（今日の地図）
2. **GFとは？**（この会社の言葉・リワードの意味）
3. **ナノコネとは？**
4. **IT業界とは？** → **IT業界での職種**（座標の補完）
5. **労働環境**（余裕があるとき）

当日公式で通すのは 1 の前半と、可能なら 2 の1見開き → **アイスブレイク開始**。
